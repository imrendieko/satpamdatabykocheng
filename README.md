# 🐱 Cat Security Scanner

Website cyber security untuk mengecek indikasi kompromi akun setelah terkena phishing.
Dilengkapi dengan animasi kucing yang lucu dan interaktif!

## 🔒 Fitur Utama

### Scanning

- ✅ Scan email untuk mendeteksi kebocoran data
- ✅ Scan nomor HP untuk indikasi spam/scam
- ✅ Pemeriksaan browser (service worker, localStorage, dll)
- ✅ Risk score assessment (Aman/Waspada/Risiko Tinggi)

### Privasi

- 🔒 **TIDAK menyimpan data apapun ke database**
- 🔒 Semua scan bersifat realtime
- 🔒 Data langsung dihapus dari memory setelah scan
- 🔒 Tidak ada logging request pengguna
- 🔒 Tidak menggunakan cookies tracking

### Keamanan Browser

- 🛡️ Deteksi service worker mencurigakan
- 🛡️ Pemeriksaan localStorage
- 🛡️ Cek notification permission
- 🛡️ Deteksi popup abuse

### UI/UX

- 😺 Banyak animasi kucing lucu dan interaktif
- 📱 Responsive mobile design
- ✨ Animasi scanning realtime
- 🎨 UI yang menyenangkan dengan Tailwind CSS

## 🚀 Cara Install & Menjalankan

### Prerequisites

- Node.js (v14 atau lebih tinggi)
- npm atau yarn

### Langkah 1: Clone atau download project

```bash
git clone https://github.com/yourusername/cat-security-scanner.git
cd cat-security-scanner
```

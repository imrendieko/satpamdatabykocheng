Cara Kerja Website

  1. 📝 Kamu masukin email/nomor HP ➜ sistem langsung validasi formatnya. Kalau ada typo, bakal diingetin dulu.
  2. 🚀 Begitu klik “Scan”, frontend bikin request realtime ke server buat ngecek kemungkinan data bocor.
  3. 🛰️ Server nerusin pengecekan ke layanan intel kebocoran data (database breach) dan balikin hasil mentahnya.
  4. 📊 Hasil mentah diproses di browser: dihitung risk score, diringkas jadi poin-poin, terus ditampilin ke kamu.
  5. ⏳ Sambil nunggu hasil, animasi loading jalan biar kamu tahu proses lagi kerja (bukan ngelag, hehe).
  6. 🧽 Setelah hasil keluar, input dibersihkan dari memory supaya gak ngendap di sesi browser kamu.
  7. 🛠️ Kalau kamu klik “Perbaikan Cepat”, sistem bakal bantu bersihin cache, reset session, atau hapus service worker.

Fun fact: proses ini jalan realtime, jadi tiap scan itu fresh, bukan data lama.

Dan yes, gak ada data yang disimpan ke database. Zero storage beneran.
